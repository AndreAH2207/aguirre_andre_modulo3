# Política de liberación de ventas

## Pasos para liberar un pedido
Antes de liberar un pedido para despacho se verifica, en este orden: que el cliente y el SKU existan, que haya stock suficiente, que el cliente no esté en hold, que tenga línea de crédito disponible y que el pedido no alcance el monto de revisión. Si todo se cumple, el pedido se libera.

## Stock insuficiente
Si la cantidad solicitada supera el stock disponible, el pedido se rechaza y no se envía a Finanzas, porque no se puede despachar. El cliente puede ingresar un nuevo pedido por la cantidad disponible.

## Cliente o SKU inexistente
Si el cliente o el SKU no están registrados, el pedido se rechaza y se solicita verificar el identificador. No se intenta adivinar un identificador parecido.
